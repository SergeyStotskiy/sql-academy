# SQL — интерактивный учебник

Одностраничное веб-приложение для изучения SQL. SQLite выполняется прямо в браузере
(через [sql.js](https://github.com/sql-js/sql.js), WASM-сборку SQLite) — сервер и бэкенд не нужны.

26 уроков в 6 модулях — от основ реляционных БД и `SELECT` до `JOIN`, подзапросов, CTE, `UNION`,
`INSERT`/`UPDATE`/`DELETE`, типов данных, оконных функций, транзакций, представлений, индексов и
ограничений. В каждом уроке — подробное объяснение (с расчётом на новичка и отдельными пометками
«зачем это тестировщику»), пример с живым выполнением и упражнения с автоматической проверкой.

Плюс **тренажёр** — 45 отдельных заданий (15 лёгких, 20 средних, 10 сложных) с фильтрами по
сложности, подсказками за спойлерами (сначала «с чего начать», потом конкретная конструкция) и
разбором решения. Часть сложных заданий — сверка данных между таблицами в духе реальной работы
тестировщика: найти оплату, не совпадающую с суммой заказа; заказ, отгруженный раньше оплаты;
отзыв на товар, который клиент не покупал.

Дополнительно:

- **Живой предпросмотр** — пока вы печатаете запрос, подсвечивается, какие строки исходной таблицы
  проходят `WHERE` и какие столбцы попадают в результат.
- **Кнопка «🗄️ Посмотреть БД»** на любой странице — модалка со схемой связей (ER-диаграмма) и полным
  содержимым всех таблиц.
- **«↺ Сбросить базу»** — вернуть учебную базу в исходное состояние после экспериментов с
  `INSERT`/`UPDATE`/`DELETE`.
- **Песочница** для свободных запросов.
- **Прогресс** сохраняется в браузере (localStorage): решённые упражнения и задания, общий счётчик
  в боковой панели и возврат к тому разделу, где вы остановились. Кнопка «📈 Прогресс» позволяет
  выгрузить прогресс в файл и загрузить его в другом браузере или на другом компьютере, а также
  сбросить всё и начать заново.

Темы, которые SQLite не умеет выполнять (хранимые процедуры и функции, планировщик событий,
`CREATE DATABASE`, блокировки строк, `REGEXP`), даны как справочные уроки с синтаксисом
MySQL/PostgreSQL и явной пометкой, что здесь они не выполняются.

## Как открыть

Открыть `index.html` напрямую в браузере (двойным кликом) не получится из-за `fetch('schema.sql')` —
браузеры блокируют `fetch` для `file://`. Нужен любой локальный статический сервер:

```bash
npm run serve         # http://localhost:8000, использует python3 -m http.server
```

или задеплоить папку целиком как статический сайт (GitHub Pages, Netlify и т.п.). Нужен доступ
в интернет при первой загрузке страницы — библиотека sql.js подключается с CDN.

Прогресс (какие упражнения уже пройдены) сохраняется в `localStorage` браузера.

## Проверка учебного контента

```bash
npm install
npm test
```

Прогоняет все SQL-запросы (примеры и эталонные решения упражнений) из `lessons.js` против
`schema.sql` на Node-версии sql.js — ловит опечатки и ошибки в самих уроках до того, как их
увидит ученик.
